# backroom-ytmusic

YouTube Music source module for Backroom (8spine module format).

Add it in the app under Modules → Add, with this URL:

    https://raw.githubusercontent.com/gliddd4/backroom-ytmusic/main/modules/youtubeMusicDirect.js

Based on [nvmindl/8spine-ytmusic](https://github.com/nvmindl/8spine-ytmusic). Change: audio-only AAC is
tried before the muxed progressive MP4, so the quality setting applies.

This module is third-party code that runs on your device and talks to YouTube directly. It is not part of,
hosted by, or endorsed by the Backroom app. You are responsible for complying with YouTube's terms.
